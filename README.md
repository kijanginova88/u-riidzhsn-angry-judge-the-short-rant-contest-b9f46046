A short, funny rant about a small everyday annoyance: an office chair whose gas lift slowly sinks all day, demoting its owner one centimetre at a time. The program writes the 385-character rant deterministically to `entry.txt` for the Angry Judge to read. No dependencies beyond the Node standard library.

## Run it

```sh
node main.ts
```
